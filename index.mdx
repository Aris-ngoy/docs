Welcome to the **react-native-nitrowind** documentation. Nitrowind is a high-performance React Native SDK built on the [Nitro Modules](https://github.com/mrousavy/nitro) JSI bridge, giving you direct access to native iOS (Swift) and Android (Kotlin) functionality straight from JavaScript. Every API is fully typed so you get compile-time safety without sacrificing any runtime speed.

## Get Started in Three Steps

<Steps>
  <Step title="Install the packages">
    Add both `react-native-nitrowind` and the underlying `react-native-nitro-modules` peer dependency to your project.

    ```bash
    npm install react-native-nitrowind react-native-nitro-modules
    ```

    Nitrowind supports **bare React Native v0.76+** and **Expo SDK 57+**. No additional native linking steps are required on either platform.
  </Step>
  <Step title="Import Nitrowind">
    Pull the `Nitrowind` object into any JavaScript or TypeScript file in your app.

    ```ts
    import { Nitrowind } from 'react-native-nitrowind';
    ```

    TypeScript definitions are bundled automatically — no `@types` package needed.
  </Step>
  <Step title="Call a native method">
    Invoke native functionality directly. Calls cross the JSI bridge synchronously with no serialization overhead.

    ```ts
    const result = Nitrowind.sum(12, 30);
    console.log(result); // => 42
    ```

    Every method is fully typed, so your editor will autocomplete arguments and return values as you type.
  </Step>
</Steps>
